# Hotkey Fallback demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Hotkey Fallback](https://github.com/mnaoumov/obsidian-hotkey-fallback) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **`Hotkey Fallback`: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `hotkey-fallback-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-hotkey-fallback/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `hotkey-fallback-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
